SignBridge Desktop Application
============================

🎯 **What is SignBridge?**
SignBridge is an AI-powered desktop application that converts speech to sign language animations in real-time. It helps bridge communication between hearing and deaf communities.

🚀 **Quick Installation**
1. Double-click "SignBridge_0.1.0_arm64-setup.exe"
2. Follow the installation wizard
3. Launch SignBridge from your Start Menu

💻 **System Requirements**
- Windows 10/11 (ARM64 architecture)
- Snapdragon X Elite processor
- 8GB RAM minimum
- 2GB free disk space
- Internet connection (for first-time setup)

🎮 **Features**
- Real-time speech-to-text transcription
- Automatic sign language translation
- 3D avatar animation
- Text simplification for clarity
- Support for American Sign Language (ASL)

🔧 **First Time Setup**
- The app will automatically download AI models on first run
- Initial setup may take 2-3 minutes
- Ensure you have a stable internet connection

🎤 **How to Use**
1. Click the microphone button to start recording
2. Speak clearly into your microphone
3. Watch the 3D avatar perform sign language
4. Use text input for manual translation

❓ **Troubleshooting**
- If the app doesn't start, ensure you have the latest Windows updates
- For audio issues, check your microphone permissions
- If models fail to download, check your internet connection
